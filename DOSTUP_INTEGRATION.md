# Интеграция с «Доступ до правди» (dostup.org.ua) — полный протокол

> **Документ для ИИ-агентов и разработчиков.** Здесь описан полный HTTP-протокол
> портала dostup.org.ua (украинский аналог WhatDoTheyKnow, форк Alavetelli),
> проверенный вживую 26–27.08.2026. По этой инструкции нейросеть или разработчик
> может реализовать клиент на ЛЮБОМ языке — весь протокол это обычные HTTP-запросы
> + cookies + CSRF-токены из HTML. JavaScript и браузер НЕ нужны.
>
> Готовая реализация на Go: пакет `internal/dostup` этого репозитория.

---

## 1. Что такое «Доступ до правди» и зачем это боту

- Портал публикует информационные запросы граждан к ~2150 госорганам Украины
  по ЗУ «Про доступ до публічної інформації».
- Запрос, поданный через портал: (а) доставляется органу, (б) становится
  **публичным** (дополнительный общественный контроль), (в) получает страницу
  отслеживания с дедлайном ответа.
- Это решает главную проблему email-канала: письма госорганам часто не доходят
  или попадают в спам; портал же — официальный канал с трекингом.

**Ключевое открытие разведки:** reCAPTCHA v2 есть только в браузерном интерфейсе.
Сервер принимает все формы обычными POST-запросами без капчи. Все CSRF-токены
отдаются предзаполненными в HTML.

---

## 2. Общие правила всех запросов

| Параметр | Значение |
|---|---|
| Base URL | `https://dostup.org.ua` |
| Метод | GET / POST, `Content-Type: application/x-www-form-urlencoded` |
| User-Agent | Обязательно реалистичный браузерный (ботовые UA отклоняются) |
| Cookies | Сессия в cookie `_wdtk_cookie_session` — хранить между запросами |
| Кодировка | UTF-8 везде (украинский текст в полях форм) |

Редиректы (301/302/303) НЕ следовать автоматически — читать `Location` вручную
(логин и подача запросов возвращают 302 в норме).

## 3. Регистрация нового аккаунта

### 3.1. Временный ящик mail.tm (для приёма писем портала)

API: `https://api.mail.tm` (JSON, Bearer-токен). **Принимает письма, но не отправляет**
(`POST /messages` → 405 — это фича, а не баг: подтверждения приходят СЮДА).

```
GET  /domains?page=1                  → {"hydra:member":[{"domain":"emalupe.com","isActive":true},...]}
POST /accounts  {address, password}   → 201 Created  (422 = ящик существует)
POST /token     {address, password}   → {"token":"<Bearer>"}
GET  /messages?page=1                 → список писем (Authorization: Bearer <token>)
GET  /messages/<id>                   → полное письмо (поле "text")
```

### 3.2. Подача формы регистрации

**Шаг 1** — `GET /profile/sign_in?r=%2F`. Из HTML извлечь токен регистрации:

```html
<input type="hidden" name="token" id="signup_token" value="XXXXXXXXXXXXXXXXXXXX" />
```

**Шаг 2** — `POST /profile/sign_up` со следующими полями:

| Поле | Значение |
|---|---|
| `user_signup[email]` | адрес mail.tm |
| `user_signup[name]` | имя (напр. «Сергій Акімов») |
| `name_public_ok` | `1` — **ОБЯЗАТЕЛЬНО** (публичность имени; без него — ошибка) |
| `user_signup[password]` | пароль сайта **>= 12 символов** (короткий отклоняется) |
| `user_signup[password_confirmation]` | тот же пароль |
| `token` | значение signup_token из шага 1 |

Успех: ответ содержит «Тепер перевірте вашу пошту» (или HTTP 302).

**Шаг 3** — ждать письмо от `do-not-reply@dostup.org.ua` с темой
«Підтвердіть ваш акаунт» (обычно < 1 минуты, poll mail.tm каждые 10 с).
В тексте письма — ссылка активации вида:

```
https://dostup.org.ua/c/<уникальный_код>
```

**Шаг 4** — `GET` по этой ссылке (с тем же cookie-jar!). Ссылка одновременно
активирует аккаунт и выполняет автовход — она работает многократно как
безпарольный вход (удобно сохранять пользователю).

### 3.3. Известные ловушки регистрации

1. Пароль < 12 символов → «Пароль закороткий».
2. Чекбокс `name_public_ok` выглядит необязательным, но он обязателен.
3. В браузере форма защищена reCAPTCHA v2 — но сервер POST без `g-recaptcha-response` принимает.

## 4. Вход (логин)

**Шаг 1** — `GET /profile/sign_in`. Извлечь:

```html
<input type="hidden" name="token" id="signin_token" value="XXXXXXXXXXXXXXXXXXXX" />
```

**Шаг 2** — `POST /profile/sign_in`:

| Поле | Значение |
|---|---|
| `authenticity_token` | `""` (пустой — JS его не заполняет для этой формы) |
| `user_signin[email]` | email |
| `user_signin[password]` | пароль |
| `remember_me` | `1` |
| `token` | signin_token из шага 1 |
| `modal` | `""` |
| `commit` | `Увійти` |

Успех: HTTP 302 + рабочая cookie `_wdtk_cookie_session`.
Проверка сессии: `GET /` → в HTML есть `sign_out` или «Мої запити».

⚠️ **Важно:** если сессия уже активна, `GET /profile/sign_in` вернёт 302 —
не считать ошибкой, сначала проверяйте `IsLoggedIn`.

## 5. Поиск распорядителя (госоргана) в каталоге

```
GET /body/list/all?public_body_query=<URL-encoded название>
```

Ответ — HTML со ссылками вида:

```html
<a href="/body/dierzhavnie_biuro_rozsliduvan">Державне бюро розслідувань</a>
```

Парсить регуляркой `href="/body/([a-z0-9_]+)"[^>]*>(.*?)</a>`, выкидывая
служебные `list/...`. Слаг — постоянный идентификатор органа.

Примеры проверенных слагов (по состоянию на 08.2026):

| Орган | slug | id |
|---|---|---|
| Державне бюро розслідувань | `dierzhavnie_biuro_rozsliduvan` | 25955 |
| Державна судова адміністрація | `dierzhavna_sudova_administratsiia_ukrayini` | 25938 |
| Вища рада правосуддя | `vishcha_rada_pravosuddia` | — |
| Вищий антикорупційний суд | `vishchii_antikoruptsiinii_sud` | — |

**Важно:** судов в каталоге мало (районных судов почти нет — напр. Печерського
райсуду Києва нет). Для судов используйте ДСА или email-канал.

## 6. Подача информационного запроса (ядро протокола)

Обязательно **два шага** (preview → submit). Попытка сразу отправить
(preview=0 с первого токена) не пройдёт.

### Шаг 1 — страница формы

```
GET /new/<slug>
```

Извлечь из HTML:

```html
<input name="authenticity_token" ... value="TOKEN_1" />
<input name="info_request[public_body_id]" ... value="25955" />
```

### Шаг 2 — предпросмотр

```
POST /new
  authenticity_token           = TOKEN_1
  info_request[title]          = <тема, до ~150 симв.>
  outgoing_message[body]       = <полный текст запроса>
  info_request[public_body_id] = <id органа>
  submitted_new_request        = 1
  preview                      = 1
  commit                       = Наступний крок: попередній перегляд
```

Ответ 200 — страница предпросмотра с НОВЫМ токеном (TOKEN_2) в форме.
Если токена нет — ошибка валидации (block `errorExplanation` в HTML).

### Шаг 3 — финальная отправка

```
POST /new
  authenticity_token           = TOKEN_2
  info_request[title]          = <та же тема>
  outgoing_message[body]       = <тот же текст>
  info_request[public_body_id] = <тот же id>
  info_request[tag_string]     =   (пусто)
  submitted_new_request        = 1
  preview                      = 0
  submit                       = Відправити та опублікувати
```

Успех: в ответе есть `href="/request/<slug_запроса>"` → публичный URL:
`https://dostup.org.ua/request/<slug_запроса>`.
Часто после успеха — HTTP 302 на страницу запроса.

### ⚠️ Ошибка 500 «Забагато запитів»

Финальный POST может вернуть **HTTP 500** («Перепрошуємо, виникла проблема…»).
Это rate limit / известный баг портала. Запрос при этом обычно НЕ создаётся.
**Лечение:** пауза 3–5 минут и повтор Шагов 1–3 с нуля (новые токены).
Опыт: первый сабмит после паузы проходит.

## 7. Список «Мої запити»

URL персонализирован. Схема: `GET /` → из ссылки «Мої запити» взять
`/user/<имя>/requests` → `GET` по нему → парсить
`href="(/request/[^"#]+)"[^>]*>(.*?)</a>`.

## 8. Готовый Go-пакет `internal/dostup`

Чистая стандартная библиотека (нет внешних зависимостей!). Файлы:

| Файл | Содержимое |
|---|---|
| `client.go` | Client: New / Login / EnsureSession / SearchBodies / SubmitRequest / MyRequests, персистентная cookie-сессия в JSON |
| `mailtm.go` | CreateMailbox / LoginMailbox / ListMessages / GetMessage |
| `register.go` | RegisterFullFlow — полный цикл: ящик → регистрация → ожидание письма → активация по /c/-ссылке |

### Быстрый старт

```go
client := dostup.New(".dostup_session.json") // файл сессии
client.SetCredentials(email, password)       // авто-релейин при истечении
if err := client.Login(email, password); err != nil { /* ... */ }

// Поиск органа
bodies, _ := client.SearchBodies("Державне бюро розслідувань")

// Подача запроса
info, err := client.SubmitRequest(bodies[0].Slug, "Тема запиту", "Текст...")
if err != nil {
    if errors.Is(err, dostup.ErrRateLimited) {
        // подождать 3–5 минут и повторить
    }
}
fmt.Println(info.URL) // https://dostup.org.ua/request/...
```

### Регистрация нового аккаунта одной функцией

```go
res, err := dostup.RegisterFullFlow(
    ".dostup_session.json",          // файл сессии
    "Сергій Акімов",                 // имя
    "mybot_user_12345",              // логин ящика (латиница)
    "SuperSecretPass2026!",          // пароль сайта (>= 12 симв.!)
    5*time.Minute,                   // ожидание письма-подтверждения
)
// res.Client — залогиненный клиент
// res.Account.Address — ящик mail.tm (сюда придут ответы портала)
```

### Живой тест против продакшена

```bash
go run ./tools/dostup-test -email <email> -password <пароль>
```

Проверяет: вход → поиск → «Мої запити». Референсный прогон 27.08.2026:
все 3 проверки за 2.3 с.

## 9. Интеграция в Telegram-бота

1. **Конфиг** (`.env`):

```env
DOSTUP_EMAIL=akimovcasehw3jf3aw@emalupe.com   # аккаунт портала
DOSTUP_PASSWORD=DostupPravda2026!Ak           # пароль
DOSTUP_SESSION_FILE=.dostup_session.json      # cookie-сессия (optional)
```

Без этих переменных бот работает как раньше (канал отключён).

2. **В потоке `/new`** на экране подтверждения появляется кнопка
   «🌐 Надіслати через Доступ до правди» → бот ищет орган в каталоге по
   названию черновика → показывает совпадения → пользователь выбирает →
   двухшаговая подача → бот возвращает публичный URL запроса и дедлайн.

3. **Обработка ошибок в UI:**
   - `dostup.ErrRateLimited` → сообщение «натисніть повторно через 3–5 хвилин,
     чернетка збережена»;
   - орган не найден → подсказка отправить email-каналом;
   - сессия истекла → автоматический релейин по DOSTUP_EMAIL/PASSWORD.

## 10. Чек-лист «если что-то сломалось»

| Симптом | Причина | Решение |
|---|---|---|
| GET форм возвращает 302 вместо 200 | уже залогинены | проверять `IsLoggedIn()` до `Login()` |
| 500 на финальном POST | rate limit | пауза 3–5 мин, повтор с новыми токенами |
| «Пароль закороткий» | < 12 символов | генерировать пароль длиннее |
| Регистрация не шлёт письмо | ящик переполнен/домен умер | создать новый ящик mail.tm |
| Органа нет в поиске | не зарегистрирован как распорядитель | проверить слаг вручную на сайте |
| 403/403 на запросах | пустой/ботовый User-Agent | слать реалистичный UA |
| Сессия слетела | cookie истёк | `EnsureSession()` → авто-релейин |

## 11. Этика и правовые рамки

- Портал публичный, запросы по нему — законное право гражданина
  (ст. 19–20 ЗУ «Про доступ до публічної інформації»).
- Запросы **публичны**: не включайте персональные данные третьих лиц.
- Rate limit — реальная защита портала: не автоматизируйте массовые рассылки,
  держите человекоподобный темп (пауза между запросами, разумные лимиты в боте
  уже есть: 3 запроса/час на пользователя).
